# Kliftra

Kliftra is a React Native mobile app UI project focused on building a clean, modern authentication flow and user onboarding experience. This repo contains the front-end structure, screens, and navigation setup for the Kliftra application. This app was intended to help rockclimbers plan a beta. 

## Features

- Modern mobile UI built with **React Native + TypeScript**
- Authentication screens
  - Create Account
  - Login
  - Forgot Password
- Organized screen/component structure for scalability
- Designed to be easily extended with backend auth (Firebase, Supabase, custom API, etc.)

## Tech Stack

- **React Native**
- **TypeScript**
- **Expo** (if used in this repo)
- React Navigation (recommended/commonly used for navigation)
- Component-based UI structure
